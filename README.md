# USD & Solaris Lab

A hands-on USD, Houdini Solaris and Arnold course for lighters.

- **Practice:** 16 lessons and 6 broken-shot missions in a mini Solaris built around one street shot
- **Reference:** 22 chapters across Basic, Intermediate and Advanced
- **Arnold:** where settings live in USD, render options, operators, imagers, AOVs and light groups, debugging
- **Viewport:** a tour of the controls, a light placement trainer, a hotkey drill, the Render Gallery
- **Cheat sheet:** the essentials on one page

One static `index.html`, no build step. Hosted with GitHub Pages.

Companion to [Light & Shade Lab](https://ramstammina.github.io/light-shade-lab/).
